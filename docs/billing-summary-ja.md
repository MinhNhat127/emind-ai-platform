# 課金・請求ルール 概要（報告用）

E-Mind Platform における課金・請求の基本ルールをまとめたものです。

---

## 1. 基本方針

- 月額サブスクリプション制とする。
- 料金は **席（シート）単位** で課金する（利用者個人単位ではなく、契約席数に対して課金）。
- **ご契約単位**（企業契約は会社ごと／個人契約は個人ごと）に **請求基準日（アンカー日）** を設定し、毎月同日に請求を確定・決済する（月末一括ではない）。
- 企業契約の場合、所属メンバー（席）は **全員が同一の請求サイクル・基準日** で請求される（メンバーごとに基準日が分かれることはない）。

## 2. 無料トライアル

- 全ユーザー一律 **14日間** 無料。
- トライアル期間中は課金なし（¥0）。

## 3. 請求サイクルと締め日

登録日を **6/10** とした場合の例：

| 項目 | 日付 |
|---|---|
| 登録日（トライアル開始） | 6/10 |
| トライアル終了 | 6/23（14日間） |
| **請求基準日（アンカー日）** | 毎月 **24日** |
| 締め日 | 毎月 23日 |
| 請求確定日・引き落とし日 | 毎月 24日 |

- **締め日（23日）** … 当月の追加・削除・入れ替えを確定する日。
- **請求確定日（24日）** … 金額を確定し、カードより引き落とす日。

## 4. 初月割引

- 割引は **初回課金月（トライアル終了直後の1ヶ月）にのみ適用** する。
- 当該月は必ず「まるまる1ヶ月」となるため、日割りと割引が重ならず、計算が明快になる。

## 5. メンバー（席）の増減

### 5-1. 追加（席数が増える場合）
- 追加時点では請求しない。
- **次回請求日** に、当月の利用日数分（日割り）＋ 翌月分 をまとめて請求する。

### 5-2. 削除・無効化（席数が減る場合）
- **返金なし**。
- 当該メンバーは **現サイクル終了まで利用可能**。
- 翌サイクルより席数を減算する。

### 5-3. 入れ替え（人の交代、席数は不変）
- 1名無効化＋1名追加のように **席数が変わらない場合、追加料金は発生しない**。
- 支払済みの空席を新メンバーが引き継ぐ。
- 席数が純増した分のみ日割り課金する。

## 6. 日割り計算

- 1日あたり単価 ＝ 月額 ÷ 当該サイクルの実日数。
- サイクルの日数は月により異なる（28〜31日）ため、常に対象サイクルの実日数で計算する。

## 7. 特記事項

- 請求基準日が 29〜31日 となる場合、当該日が存在しない月はその月の末日を請求基準日とする。

---

## 計算例

**前提：** ¥3,000 / 席・月、請求基準日 24日、サイクル 6/24〜7/23（30日、日割り ¥100）。

**7/4 に 1席 追加した場合：**

| 項目 | 計算 | 金額 |
|---|---|---|
| 日割り分（7/4〜7/23＝20日）※後払い | 20 × ¥100 | ¥2,000 |
| 翌月分（7/24〜8/23）※前払い | 1ヶ月 | ¥3,000 |
| **7/24 請求額** | | **¥5,000** |

翌月以降は通常どおり ¥3,000 / 月。
